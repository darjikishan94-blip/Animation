11.5 In changing the state of a gas adiabatically from an equilibrium state A to another equilibrium state B, an amount of work equal to 22.3 J is done on the system. If the gas is taken from state A to B via a process in which the net heat absorbed by the system is 9.35 cal, how much is the net work done by the system in the latter case ? (Take 1 cal = 4.19 J)

Given

  • Adiabatic A → B: 22.3 J of work done on the gas. Other path: 9.35 cal of heat absorbed; 1 cal = 4.19 J.

Asked

The net work done by the gas on the second path.

Why there is no animation

  • This is a direct calculation with nothing moving to show; the page shows the question and a worked answer.

Answer

  1. Adiabatic: Q = 0, so ΔU = +22.3 J (work done on the gas).
  2. ΔU depends only on A and B, so it is 22.3 J on the other path too.
  3. Q = 9.35 × 4.19 ≈ 39.2 J; Wby gas = Q − ΔU ≈ 39.2 − 22.3 ≈ 16.9 J.

About 16.9 J done by the gas.
