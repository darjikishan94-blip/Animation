14.17 A pipe 20 cm long is closed at one end. Which harmonic mode of the pipe is resonantly excited by a 430 Hz source ? Will the same source be in resonance with the pipe if both ends are open? (speed of sound in air is 340 m s–1).

Given

  • L = 20 cm; closed at one end; source 430 Hz; v = 340 m s−1.

Asked

The harmonic excited; resonance if both ends are open?

How the animation is drawn

  • Standing-wave patterns shown as displacement amplitude.

Answer

  1. Closed at one end: νn = n v/4L, n odd. Fundamental = 340/(4 × 0.20) = 425 Hz ≈ 430 Hz: the fundamental (first harmonic) is excited.
  2. Both ends open: νn = n v/2L = 850 Hz, 1700 Hz, …: none near 430 Hz, so no resonance.

The fundamental (≈ 425 Hz); no resonance with both ends open.
