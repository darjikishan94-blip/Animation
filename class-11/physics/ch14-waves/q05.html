14.5 You have learnt that a travelling wave in one dimension is represented by a function y = f (x, t) where x and t must appear in the combination x – v t or x + v t, i.e. y = f (x ± v t). Is the converse true? Examine if the following functions for y can possibly represent a travelling wave : (a) (x – vt )2 (b) log [(x + vt)/x0] (c) 1/(x + vt)

Given

  • Three functions of x ± vt.

Asked

Is the converse true? Which can be travelling waves?

Why there is no animation

  • This question asks for explanations or a classification rather than describing one situation to follow; the page shows the question and a worked answer.

Answer

  1. No: a function of x ± vt must also be physically acceptable: the displacement must be finite everywhere and at all times.
  2. (a) (x − vt)2 grows without limit: not acceptable.
  3. (b) log[(x + vt)/x₀] is infinite at x + vt = 0 (and undefined beyond): not acceptable.
  4. (c) 1/(x + vt) is infinite at x = −vt. (NCERT’s answer key accepts (c) as the only finite one; strictly it too diverges at that point.)

The converse is not true; (a) and (b) cannot be waves, and (c) is acceptable only away from x = −vt.
