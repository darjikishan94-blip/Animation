1.10 State the number of significant figures in the following : (a) 0.007 m2 (b) 2.64 × 1024 kg (c) 0.2370 g cm–3 (d) 6.320 J (e) 6.032 N m–2 (f) 0.0006032 m2

Given

  • Six measured values.

Asked

The number of significant figures in each.

Why there is no animation

  • This is a calculation (or an explanation) with no physical situation to animate; the page shows the question and a worked answer.

Answer

  1. (a) 0.007: leading zeros do not count: 1.
  2. (b) 2.64 × 1024: the power of ten does not count: 3.
  3. (c) 0.2370: the trailing zero after the decimal point counts: 4.
  4. (d) 6.320: 4.
  5. (e) 6.032: zeros between digits count: 4.
  6. (f) 0.0006032: 4.

(a) 1 (b) 3 (c) 4 (d) 4 (e) 4 (f) 4
