2.13 Figure 2.11 shows the x-t plot of one-dimensional motion of a particle. Is it correct to say from the graph that the particle moves in a straight line for t < 0 and on a parabolic path for t > 0 ? If not, suggest a suitable physical context for this graph.

Given

  • Fig. 2.11: x = 0 for t < 0; for t > 0, x grows like a parabola.

Asked

Whether the path is straight then parabolic; a physical context.

How the animation is drawn

  • The acceleration is illustrative; none is given.

Answer

  1. No. An x–t graph is not the path: in one-dimensional motion the particle always moves along a straight line.
  2. The graph says: at rest at x = 0 before t = 0, then x ∝ t2, i.e. uniformly accelerated from rest.
  3. Context: a car at rest at a signal that starts moving with constant acceleration at t = 0 (or a stone dropped at t = 0).

No: the path is a straight line; e.g. a body at rest that starts uniformly accelerating at t = 0.
