2.7 Read each statement below carefully and state with reasons and examples, if it is true or false ; A particle in one-dimensional motion (a) with zero speed at an instant may have non-zero acceleration at that instant (b) with zero speed may have non-zero velocity, (c) with constant speed must have zero acceleration, (d) with positive value of acceleration must be speeding up.

Given

  • Four statements about one-dimensional motion.

Asked

True or false, with reasons and examples.

Why there is no animation

  • This question asks for an explanation (or a judgement) rather than describing one physical situation; the page shows the question and a worked answer.

Answer

  1. (a) True: a ball thrown up has zero speed at the top but acceleration g.
  2. (b) False: speed is the magnitude of velocity, so zero speed means zero velocity.
  3. (c) True (NCERT): in one dimension constant speed means the velocity cannot reverse without stopping; reversing instantly at the same speed would need infinite acceleration, which is unphysical.
  4. (d) False: a positive acceleration speeds the particle up only if its velocity is also positive; with negative velocity (e.g. a ball rising, with downward taken positive) it slows down.

(a) True (b) False (c) True (d) False
