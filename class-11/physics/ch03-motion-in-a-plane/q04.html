3.4 State with reasons, whether the following algebraic operations with scalar and vector physical quantities are meaningful : (a) adding any two scalars, (b) adding a scalar to a vector of the same dimensions , (c) multiplying any vector by any scalar, (d) multiplying any two scalars, (e) adding any two vectors, (f) adding a component of a vector to the same vector.

Given

  • Six operations.

Asked

Whether each is meaningful, with reasons.

Why there is no animation

  • This question asks for a classification or a judgement rather than describing one physical situation; the page shows the question and a worked answer.

Answer

  1. (a) Meaningful only if the two scalars are the same kind of quantity (same dimensions): mass + mass, not mass + time.
  2. (b) Not meaningful: a scalar and a vector cannot be added.
  3. (c) Meaningful: the result is a vector (e.g. mass × acceleration = force).
  4. (d) Meaningful: e.g. power × time = energy.
  5. (e) Meaningful only if both vectors are the same kind of quantity.
  6. (f) Meaningful: a component is itself a vector of the same kind and dimensions.

(a) only for like scalars (b) no (c) yes (d) yes (e) only for like vectors (f) yes
