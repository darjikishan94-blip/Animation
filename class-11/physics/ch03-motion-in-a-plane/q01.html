3.1 State, for each of the following physical quantities, if it is a scalar or a vector : volume, mass, speed, acceleration, density, number of moles, velocity, angular frequency, displacement, angular velocity.

Given

  • Ten physical quantities.

Asked

Which are scalars and which are vectors.

Why there is no animation

  • This question asks for a classification or a judgement rather than describing one physical situation; the page shows the question and a worked answer.

Answer

  1. Scalars (magnitude only): volume, mass, speed, density, number of moles, angular frequency.
  2. Vectors (magnitude and direction): acceleration, velocity, displacement, angular velocity.

Scalars: volume, mass, speed, density, number of moles, angular frequency. Vectors: acceleration, velocity, displacement, angular velocity.
