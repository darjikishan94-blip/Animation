3.5 Read each statement below carefully and state with reasons, if it is true or false : (a) The magnitude of a vector is always a scalar, (b) each component of a vector is always a scalar, (c) the total path length is always equal to the magnitude of the displacement vector of a particle. (d) the average speed of a particle (defined as total path length divided by the time taken to cover the path) is either greater or equal to the magnitude of average velocity of the particle over the same interval of time, (e) Three vectors not lying in a plane can never add up to give a null vector.

Given

  • Five statements about vectors.

Asked

True or false, with reasons.

Why there is no animation

  • This question asks for a classification or a judgement rather than describing one physical situation; the page shows the question and a worked answer.

Answer

  1. (a) True: a magnitude is just a number with a unit.
  2. (b) False: each component of a vector (along an axis) is itself a vector.
  3. (c) False: true only for motion in a straight line without turning back; otherwise path length is larger.
  4. (d) True: path length ≥ |displacement| over the same time.
  5. (e) True: two of the vectors add to a vector in their own plane, which cannot cancel a third vector sticking out of that plane.

(a) True (b) False (c) False (d) True (e) True
