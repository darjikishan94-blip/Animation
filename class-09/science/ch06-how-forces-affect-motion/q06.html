6.6 The position-time graph for four objects A, B, C and D moving along a straight line are given in Fig. 6.37. A net force acts on: (i) Object A (ii) Object B (iii) Object C (iv) Object D

Given

  • Fig. 6.37: A — straight rising line; B — horizontal line; C — curve getting steeper; D — straight falling line.

Asked

Which object has a net force.

How the animation is drawn

  • Graphs follow the shapes in Fig. 6.37.

Answer

  1. The slope of a position–time graph is the velocity. A and D: straight lines, constant velocity. B: constant position, at rest. Zero acceleration, so no net force.
  2. C: the slope keeps increasing — it accelerates, so a net force acts on it.

(iii) Object C
