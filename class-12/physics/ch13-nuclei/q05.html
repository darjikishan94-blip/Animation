13.5 The Q value of a nuclear reaction A + b → C + d is defined by Q = [mA + mb – mC – md]c2 where the masses refer to the respective nuclei. Determine from the given data the Q-value of the following reactions and state whether the reactions are exothermic or endothermic. (i) 11H + 31H → 21H + 21H (ii) 126C + 126C → 2010Ne + 42He. Atomic masses are given to be m(21H) = 2.014102 u, m(31H) = 3.016049 u, m(126C) = 12.000000 u, m(2010Ne) = 19.992439 u.

Given

  • Atomic masses as listed; m(1H) = 1.007825 u, m(4He) = 4.002603 u; 1 u = 931.5 MeV/c2.

Asked

Q for each; exothermic or endothermic.

Why there is no animation

  • This is a direct calculation with nothing moving to show; the page shows the question and a worked answer.

Answer

  1. Electron masses cancel because the charges balance, so atomic masses can be used.
  2. (i) Q = (1.007825 + 3.016049 − 2 × 2.014102) × 931.5 = −0.00433 × 931.5 ≈ −4.03 MeV: endothermic.
  3. (ii) Q = (2 × 12.000000 − 19.992439 − 4.002603) × 931.5 = 0.004958 × 931.5 ≈ 4.62 MeV: exothermic.

(i) −4.03 MeV, endothermic (ii) +4.62 MeV, exothermic.
