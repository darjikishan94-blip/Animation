14.6 In half-wave rectification, what is the output frequency if the input frequency is 50 Hz. What is the output frequency of a full-wave rectifier for the same input frequency.

Given

  • Input 50 Hz ac.

Asked

Output frequency for half-wave and full-wave rectification.

How the animation is drawn

  • Three cycles (60 ms); curves to scale.

Answer

  1. Half-wave: one output pulse per input cycle: 50 Hz.
  2. Full-wave: both halves of each cycle give a pulse: 2 × 50 = 100 Hz.

50 Hz; 100 Hz.
