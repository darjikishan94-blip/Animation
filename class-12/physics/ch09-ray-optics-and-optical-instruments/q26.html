9.26 An angular magnification (magnifying power) of 30X is desired using an objective of focal length 1.25 cm and an eyepiece of focal length 5 cm. How will you set up the compound microscope?

Given

  • M = 30; fo = 1.25 cm; fe = 5 cm; final image at 25 cm.

Asked

Object distance and lens separation.

Why there is no animation

  • This is a direct calculation with nothing moving to show; the page shows the question and a worked answer.

Answer

  1. Eyepiece: me = 1 + D/fe = 6, so the objective must give mo = 5: vo = 5|uo|.
  2. 1/vo + 1/|uo| = 1/fo: 6/(5|uo|) = 0.8, so |uo| = 1.5 cm and vo = 7.5 cm.
  3. Eyepiece object distance: 1/ue = −1/25 − 1/5, |ue| ≈ 4.17 cm.
  4. Place the object 1.5 cm from the objective, with the lenses 7.5 + 4.17 ≈ 11.7 cm apart.

Object 1.5 cm from the objective; lenses ≈ 11.7 cm apart.
